OpenCC tw2s data notice
=======================

逐音輸入法 uses dictionary data from Open Chinese Convert (OpenCC) to build
its Taiwan Traditional Chinese -> Simplified Chinese output table.

Upstream: OpenCC
Source repository: https://github.com/BYVoid/OpenCC
Pinned release/tag: ver.1.3.1
Configuration semantics: data/config/tw2s.json
Source dictionaries used by the build step:
- data/dictionary/TSCharacters.txt
- data/dictionary/TSPhrases.txt
- data/dictionary/TWVariants.txt
- data/dictionary/TWVariantsRevPhrases.txt

OpenCC dictionary data is licensed under Apache License 2.0. A copy of that
license is included in LICENSE_OpenCC_Apache-2.0.txt.

The macOS build script may download these pinned source dictionaries into the
user cache and compile them into the input method's own ZYT2S1 runtime binary.
The installed input method does not require OpenCC, Python, or network access.
