# Shift 英文輸入取消未確認注音設計

## 目標

使用者在中文模式忘記先切換英文時，按 `Shift + 英文字母` 不得把尚未確認、可能不成句的注音候選送出。

## 規則

1. `Shift + 1～0` 與 `Shift + A～J` 保持候選快捷鍵，優先於英文輸入。
2. 單獨按下再放開 `Shift` 保持中英切換行為。
3. 按 `Shift + 英文字母` 時，若只有 `_composition` 的未確認注音，清除組字、候選和 marked text，然後直接輸入英文；不得選取或送出任何候選。
4. 若已有 `_pieceCount` 個已確認的候選／文字片段，先依原有學習與提交流程送出它們，再清除仍未確認的 `_composition`，最後輸入英文。
5. 英文大小寫沿用目前規則：沒有候選快捷鍵時，Caps Lock 關閉輸入小寫、開啟輸入大寫。

## 範圍

- 修改 macOS `ZYInputController` 的 Shift 英文字母處理。
- HTML 試用版同步同一行為。
- 新增回歸測試，驗證未確認注音不會呼叫候選選取或提交。

## 不變事項

- 正常 Enter、Space、滑鼠與 Shift 候選快捷鍵選字流程不變。
- 已確認的中文片段仍會在輸入英文前送出。
- 學習資料格式、候選排序與中英切換狀態不變。
