# README 與發行目錄整理設計

## 目標

重寫逐音輸入法 README，讓一般使用者可以從安裝到操作完整理解，同時保留足夠的開發資訊；整理發行資料夾的非建置內容，降低根目錄雜訊但不增加編譯風險。

## 原則

- 不搬動 `App/`、`Core/`、`Resources/`、`Tools/`、`Tests/`、`Licenses/`，避免不必要的路徑修改。
- 根目錄只保留專案入口、建置/解除安裝腳本、測試入口與主要原始碼目錄。
- 舊網頁原型屬於參考資料，移至 `Docs/Reference/`。
- Superpowers 設計/實作紀錄屬於開發文件，移至 `Docs/Development/`，不留重複副本。
- README 以繁體中文、台灣用語撰寫；正式名稱一律使用「逐音輸入法」。
