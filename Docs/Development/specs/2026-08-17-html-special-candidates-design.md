# HTML Emoji 與中文標點特殊候選設計

## 目標

讓 HTML 試用版的反引號 `` ` `` 與單引號 `'` 行為同步 macOS 原生輸入法：前者開啟 Emoji 候選，後者開啟中文標點候選。

## 行為

1. 中文模式按反引號開啟 Emoji 候選；按單引號開啟中文標點候選。
2. 開啟特殊候選時保留既有注音 composition 與已確認 pending 片段。
3. 特殊候選可使用方向鍵、Page Up／Down、Home／End、Enter、Space 與滑鼠選取；Esc 關閉並恢復原先注音候選。
4. 再按一次同一個特殊按鍵會關閉該特殊候選；按另一個特殊按鍵會切換候選類型。
5. 特殊候選開啟時輸入新的注音，應自動關閉特殊候選並恢復一般注音候選。
6. Emoji 與中文標點資料、每頁數量與選取行為對齊原生版；不得影響 Shift 候選快捷鍵、中英切換、Caps Lock 或 Shift 英文保護。

## 頁面底部完整使用說明

HTML 頁面底部新增常駐、可隨頁面向下捲動閱讀的「完整使用說明」區塊，不使用彈出視窗。內容需與目前輸入法行為一致，至少包含：

- 注音輸入、候選移動、翻頁、Enter／Space／滑鼠選字。
- 單按 Shift 切換英文、Shift 英文字母取消未確認注音、Shift 候選快捷鍵與 Caps Lock 規則。
- 反引號 Emoji、單引號中文標點、Esc 關閉特殊候選。
- F9 繁／簡輸出、Option 刪除已學習候選、學習資料僅保存在本機。

## 範圍

- 僅修改 HTML 試用版特殊候選狀態、操作與頁面底部說明。
- 新增可重複執行的靜態／行為回歸測試。
- 不修改 macOS 原生版既有 Emoji／標點實作。
