# OpenCC tw2s Simplified Output Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Replace the incomplete Traditional-to-Simplified mapping with an OpenCC 1.3.1 `tw2s`-compatible build step while preserving the existing fast `ZYT2S1` runtime and a repaired offline fallback.

**Architecture:** Keep `Core/ZYConversion.c` and the `ZYT2S1` format unchanged. At install time, download the four OpenCC 1.3.1 text dictionaries required by `tw2s`, flatten Taiwan variants plus phrase exceptions into the existing binary, and cache the source files. If network/source validation fails, use a bundled core-repaired `t2s.bin` that covers Taiwan variants such as `麵→面` and critical phrase exceptions.

**Tech Stack:** Python 3 build tools, C99 runtime/tests, Bash macOS installer, OpenCC 1.3.1 dictionary data (Apache-2.0).

## Global Constraints

- Candidates and learning data remain Taiwan Traditional Chinese.
- Simplified conversion happens only when committing final text.
- Use OpenCC `tw2s`, not `tw2sp`; do not rewrite Taiwan terminology into Mainland terminology.
- Runtime must not depend on Homebrew, Python, network access, or a separately installed OpenCC library.
- Preserve the current `ZYT2S1` runtime binary format and phrase-first conversion behavior.
