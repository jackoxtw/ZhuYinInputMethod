# Caret O(1) Lookup Memory Design

**Goal:** Reduce per-key transient memory pressure during candidate-window positioning without changing candidate behavior or idle panel lifecycle.

## Design

`ZYInputController::clientRect:` keeps InputMethodKit's `attributesForCharacterIndex:lineHeightRectangle:` as the primary caret source, but queries only the final inline character once. If the result is unusable, it immediately falls back to `firstRectForCharacterRange:actualRange:`, then Accessibility caret bounds, then the most recent valid caret and finally the existing emergency screen-center rectangle.

The whole lookup is wrapped in a local `@autoreleasepool` so temporary Objective-C/AppKit objects generated by caret queries are drained before returning from the lookup. The previous backward scan through every preedit character is removed, making caret lookup fixed-cost O(1) per refresh.

## Constraints

- Do not change candidate counts, ranking, dictionary, learning, Composer, OpenCC, panel lifecycle, or grow-only sizing.
- Do not reintroduce caret or mouse diagnostic files.
- Preserve zero-width insertion caret support and the existing fallback order.
