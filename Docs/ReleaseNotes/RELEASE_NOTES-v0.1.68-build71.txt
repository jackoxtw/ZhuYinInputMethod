逐音輸入法 v0.1.68 / build 71
道路／車站／機場詞庫補完版
================================

本版延續 v0.1.67 build 70 的查詢與記憶體優化，重點補齊台灣道路與交通地名。

新增內容
--------
- 台灣道路主名稱 17,565 個：只保留道路主名稱，不加入一段、二段等段別。
- 軌道車站來源列 543 筆：涵蓋台鐵、高鐵、阿里山林鐵、台北捷運、桃園機場捷運、台中捷運、高雄捷運／輕軌、新北捷運／輕軌與三鶯線。
- 台灣官方機場 17 座，另加入桃園機場、桃機、小港機場、清泉崗機場、馬公機場等常用別稱。
- 車站依系統產生「站／車站／台鐵／高鐵／捷運／機捷／桃園捷運／輕軌」等常見輸入形式。

詞庫與效能
----------
- bundled ZYDICT2：98,054 詞。
- 地名／交通生成層：21,529 個 word+pron 項目。
- 道路／車站／機場 CSV 僅用於建置；正式執行仍只讀取單一 dictionary.bin。
- macOS/POSIX dictionary 仍使用 mmap，沒有把新增 CSV 全部常駐記憶體。
- Composer workspace 維持 build 70 的約 264 KB 設計。
- HTML Canvas 原型已同步相同 dictionary.bin 資料，並加入 byte-for-byte round-trip 驗證工具。

重要回歸檢查
------------
- 忠孝東路、臺灣大道／台灣大道、凱達格蘭大道可查詢。
- 臺北車站／台北車站、高鐵左營站、捷運淡水站、機捷機場第一航廈站可查詢。
- 臺灣桃園國際機場／台灣桃園國際機場、桃園機場、小港機場、清泉崗機場可查詢。
- 多音字「期」仍保留 ㄑㄧˊ。
- Enter 防網頁聊天誤送、Learning v3、候選長度政策、固定 bucket index 與既有核心測試保留。

資料來源說明
------------
- 道路來源快照：donma/TaiwanAddressCityAreaRoadChineseEnglishJSON（MIT），原專案資料參考中華郵政；另以政府資料開放平台「全國路名資料」作現行資料來源參考。
- 軌道站名來源快照：siriushsu/taiwan-rail-live 的 track_stations.geojson；該資料目錄內容來自 TDX、OpenStreetMap、台鐵等第三方公開資料，依各原始來源授權。
- 機場清單：交通部民用航空局「機場分佈圖」。
- 詳細來源、快照 SHA 與建置方式請見 Shared/Resources/GEOGRAPHIC_WORDS.md。
